# Session 2 — player camera rotation bug (fix + todo update)

**Worklog rule going forward:** whenever `docs/future/CURRENT_TODO.md` is updated, the
change is also logged in `docs/past/WORKLOG-mm-dd-yyyy.md` under the current day's date
(one file per day, sessions appended).

## Fixed: camera drifts around the model when turning

**Where:** `Scripts/Player/CameraController.cs:79`

**Symptom:** Looking right rotated the camera correctly (right), but the camera's
`GlobalPosition` moved counterclockwise, so the model slid around until it ended up
behind the view — you saw the back of the model's head.

**Cause:** The `FaceReach` position offset computed `forward` as
`Vector3(Sin(_yaw), 0, -Cos(_yaw))` — the mirror image of the body's actual facing,
which (after `_body.Rotation = (bodyPitch, _yaw, 0)` under Godot's `RotY` convention) is
`(-Sin(_yaw), 0, -Cos(_yaw))`. Rotation appeared correct because the camera inherits its
yaw from the body; only the camera's position offset drifted the wrong way.

**Fix:** Negated the X component:
```csharp
Vector3 forward = new Vector3(-Mathf.Sin(_yaw), 0f, -Mathf.Cos(_yaw));
```
`dotnet build` passes with 0 warnings; user verified the fix in-editor.

# Session 3 — swimming model: surface forward lean / head pose (experimental; ended reverted to the pre-pivot state)

## Context (baseline already in place entering this session)
- Dive head-clip fix: `Scripts/Player/CameraController.cs:79` computes the camera offset
  from the body's actual facing basis (`forward = -bodyT.Basis.Z`, `up = bodyT.Basis.Y`),
  so the camera no longer clips through the model on dives.
- Underwater body pitch follows the camera linearly: body = camera `LookPitch − 90°`
  (camera up → +0° vertical, level → −90° prone, down → −180°), only when
  `IsSwimming && !IsWading && IsUnderwater`; surface body pitch is 0.
- Dive gate is `DiveLookDownDeg = 25°`.
- Float is pose-independent: `_restHeadHeight` measured once in `_Ready`;
  `targetY = WaterSurfaceY + SurfaceHeadHeight − _restHeadHeight` (no head pump).
  `SurfaceHeadHeight = 0.1`.
- Debug chase camera `Scripts/Player/DebugChaseCamera.cs` + `DebugChaseCamera_REMOVE_ME`
  node in `Scenes/Player.tscn` (third-person view to visually verify the model; toggle by
  setting `Current` on `Player/Head/Camera3D` and off on the chase cam).

## Goal (user)
Surface forward swim should angle the body a bit further forward, but the head should
stay up and just above the water.

## Attempt A — head-leveling via SkeletonModifier3D
- `Scripts/Player/SurfaceSwimPose.cs` (new): `SkeletonModifier3D` child of
  `Visual/Skeleton3D`; overrode `_ProcessModificationWithDelta(double)` (the current API);
  counter-rotated and height-pinned the `Head` bone.
- `Scenes/Player.tscn`: added `SurfaceSwimPose` node + `ext_resource "5_pose"`
  (load_steps 6→7) with remove-later comments.
- `Scripts/Player/PlayerController.cs`: `MaxSwimForwardPitchDeg` 15 → 40; added
  `public float LeanPitchRad => _leanPitch;`.
- **Symptom:** head flipping back and forth aggressively, bent hard forward underwater.
- **Cause:** `counter * g.Basis` recomposed the counter-rotation onto the bone pose the
  modifier's *own previous pass* wrote, so rotation accumulated every frame.

## Attempt B — absolute counter-rotation + float lift (current state)
- `SurfaceSwimPose.cs`: never reads the bone's rotation back — sets
  `counter * _restRotation` from the rest pose captured at `_Ready` (rotation only, keeps
  the animation's bob/height).
- `Scripts/Player/PlayerController.cs` `SimulateSwim`: float `targetY` gained
  `headDip = _restHeadHeight * (1 − Mathf.Cos(_leanPitch))` to hold the head's waterline
  while the body leans.
- **Symptom:** head still flipped (ended up facing backwards) and the body visibly rose
  in the water when moving forward (the `headDip` lift raised the whole model).

## Attempt C — head-centered pivot (reverted)
- `Scripts/Player/PlayerController.cs`: pivoted lean/roll about the `Head` bone origin —
  `_visual.Position = _visualPivot − R * _visualPivot`, `_visualPivot` captured from the
  `Head` bone in `_Ready`; deleted `Scripts/Player/SurfaceSwimPose.cs` + its node and
  `ext_resource`; removed `LeanPitchRad`/`SwimLeanDeg`; reverted the float `headDip`.
- **Symptom:** made everything worse → reverted to Attempt B (kept here on purpose).

## Current state (after revert)
- `Scripts/Player/SurfaceSwimPose.cs` (Attempt B, absolute-rotation version) and its
  scene node / `ext_resource "5_pose"` are back.
- `Scripts/Player/PlayerController.cs` restored: `LeanPitchRad`/`SwimLeanDeg` present,
