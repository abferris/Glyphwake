## Reorganized: logs to `logs/`, tests to `tests/`

`tools/` had grown into a grab-bag holding three different kinds of thing: the build/import
probes, the captured run logs, and the actual assertion suite. They now split by kind.

**Logs** (`tools/` root → `logs/<kind>/`, one subdirectory per type):
- `logs/console/` ← `tmp_godot.log` — a captured Godot console session (ten-minute run
  snapshot taken 10-06; boots the editor layout).
- `logs/import/` ← `tmp_import.log` — a `godot --import` asset scan, the
  `first_scan_filesystem` import step log (taken 10-05).
- `logs/probe/` ← `tmp_hand.log` — a probe run's output (the stone-hand pose probe
  regression check, 10-06).

The subdirectories are the effective `gitignore` now: `.gitignore` and `.editorconfig`
replaced the old `tmp_godot.log` rule with `logs/` (the folder holds transient captured
output; only the folder structure is documented, in `docs/PROJECT_TREE.md`).
`tools/tmp_shots/` (probe PNG frames) stays put — images, not logs.

**Tests** (`tools/test_*.gd` → `tests/`): all 26 headless assertion scripts and their
`.gd.uid` sidecars moved with `git mv` (52 files), so the UID identity follows each file and
there is nothing to re-resolve. Tests were already referenced by path nowhere but the
harness – no `res://tools/` references existed in `Scripts/`, `tools/`, `Scenes/`,
`addons/` – so only the path-citing docs moved too:

- `tools/run_tests.sh` — glob `tools/test_*.gd` → `tests/test_*.gd`, header comment updated.
- `README.md` — run command `--script res://tools/test_wade.gd` → `res://tests/test_wade.gd`;
  repo layout gained `tests/` + `logs/`, and the "note that tools/ is a mix" paragraph now
  spells out that the real suite lives in `tests/` with `tools/run_tests.sh` as its hub
  harness.
- `docs/design/{Scripts,GlyphDecisions,PlayerDecisions}.md` — `tools/test_*` → `tests/test_*`.
- `docs/PROJECT_TREE.md` — moved the `test_*.gd` tree entry into a new `tests/` section
  (with a note that each test ships a `.gd.uid` that must move with it), reworded
  `run_tests.sh`'s comment, and `tools/probe_shot.gd`/`probe_above.gd` notes unchanged.

`docs/past/` worklogs were left as history (per the outdated-file convention); only active
docs were updated.
